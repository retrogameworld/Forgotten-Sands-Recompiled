Forgotten Sands Recompiled - unofficial native PC port of Prince of Persia: The Forgotten Sands (Xbox 360)
No game files are included. You need your own disc image of the Xbox 360 disc release (title ID 5553083E).

1. Unpack this zip into a folder of its own (not under C:\Program Files).
2. Put your disc image (.iso) of the game into this folder.
3. Start ForgottenSandsRecomp.exe. The first start unpacks the disc image into the "game" folder (about 5 GB).
   After that the .iso is no longer needed.

A controller is required. Settings: settings.toml (open with Notepad, every option is explained inside).
Saves and the shader cache are in the "user" folder, the log is ForgottenSandsRecomp.log.
